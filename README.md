# 🔎 Poshukach

**Poshukach** аналізує DHCP-журнали та допомагає знайти пристрої, які підключалися до мережі, але не були знайдені у списках антивірусного захисту.

Програма працює у Windows через Python та формує CSV-файли з результатами.

## Швидкий запуск у Windows

### 1. Завантажте проєкт

1. Натисніть зелену кнопку **Code**.
2. Виберіть **Download ZIP**.
3. Розпакуйте архів, наприклад у `C:\Poshukach`.

### 2. Встановіть Python

Встановіть **Python 3.10 або новіший** з офіційного сайту Python.

Під час встановлення обов’язково позначте:

```text
Add python.exe to PATH
```

### 3. Відкрийте командний рядок у папці проєкту

Відкрийте розпаковану папку `Poshukach`, натисніть у рядку адреси Провідника, введіть `cmd` і натисніть **Enter**.

### 4. Встановіть необхідний компонент

Виконайте команду:

```bat
py -m pip install PyYAML
```

### 5. Додайте вхідні файли

Скопіюйте CSV-файли у відповідні папки:

- DHCP-журнали - `data\raw\dhcp\`
- списки MAC-адрес з антивірусів - `data\raw\av-mac\`

У цих папках є файли `data.example.csv`, за якими можна перевірити потрібний формат даних. Не перейменовуйте власні файли так, щоб їхня назва закінчувалася на `.example.csv`, оскільки такі файли програма пропускає.

### 6. Завантажте довідник виробників MAC-адрес

Цю команду потрібно виконати перед першим запуском:

```bat
py scripts\psh.py get_oui
```

Для завантаження довідника потрібне підключення до Інтернету.

### 7. Запустіть аналіз

```bat
py scripts\psh.py
```

Після завершення результати будуть збережені у папці:

```text
data\result\
```

## Основні результати

| Файл | Що містить |
|---|---|
| `dhcp-false.csv` | пристрої, не знайдені у списках антивірусів |
| `dhcp-true.csv` | пристрої, знайдені у списках антивірусів |
| `dhcp-ignore.csv` | пристрої, виключені правилами |
| `dhcp-network.csv` | мережеве обладнання |
| `dhcp-random.csv` | пристрої з рандомізованими MAC-адресами |
| `dhcp-dublicate.csv` | можливі дублікати за назвою пристрою |

## Текстовий звіт

Після виконання аналізу можна сформувати окремі текстові звіти:

```bat
py scripts\psh.py report
```

Звіти будуть створені у папці:

```text
data\report\
```

## Корисні команди

```bat
py scripts\psh.py --help
```

Показати доступні команди.

```bat
py scripts\psh.py get_oui
```

Оновити довідник виробників MAC-адрес.

```bat
py scripts\psh.py
```

Виконати повний аналіз.

```bat
py scripts\psh.py report
```

Створити текстові звіти.

## Якщо команда `py` не працює

Спробуйте ті самі команди, замінивши `py` на `python`:

```bat
python -m pip install PyYAML
python scripts\psh.py get_oui
python scripts\psh.py
```

Якщо Windows повідомляє, що Python не знайдено, перевстановіть Python і позначте пункт **Add python.exe to PATH**.
