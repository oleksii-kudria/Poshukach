# 🔎 Poshukach

**Poshukach** аналізує DHCP-журнали та допомагає знайти пристрої, які підключалися до мережі, але не були знайдені у списках антивірусного захисту.

Програма працює у Windows через Python, визначає виробників мережевих адаптерів за MAC-адресами, класифікує пристрої та формує CSV-файли і текстові звіти.

## Швидкий запуск у Windows

### 1. Завантажте проєкт

1. Натисніть зелену кнопку **Code**.
2. Виберіть **Download ZIP**.
3. Розпакуйте архів, наприклад у `C:\Poshukach`.

### 2. Встановіть Python

Встановіть **Python 3.10 або новіший** з офіційного сайту Python.

Під час встановлення обов’язково позначте:

```text
Add python.exe to PATH
```

### 3. Відкрийте командний рядок у папці проєкту

Відкрийте розпаковану папку `Poshukach`, натисніть у рядку адреси Провідника, введіть `cmd` і натисніть **Enter**.

### 4. Встановіть необхідний компонент

```bat
py -m pip install PyYAML
```

### 5. Додайте вхідні файли

Скопіюйте CSV-файли у відповідні папки:

- DHCP-журнали - `data\raw\dhcp\`
- списки MAC-адрес з антивірусів - `data\raw\av-mac\`

У цих папках є файли `data.example.csv`, за якими можна перевірити потрібний формат даних.

Файли, назва яких закінчується на `.example.csv`, програма не обробляє.

### 6. Завантажте довідник виробників MAC-адрес

Перед першим запуском виконайте:

```bat
py scripts\psh.py get_oui
```

Для завантаження довідника потрібне підключення до Інтернету. Файл буде збережено у `data\cache\oui.csv`.

### 7. Запустіть аналіз

```bat
py scripts\psh.py
```

Результати будуть збережені у:

```text
data\result\
```

### 8. Сформуйте текстові звіти

```bat
py scripts\psh.py report
```

Звіти будуть створені у:

```text
data\report\
```

## Як працює програма

Під час звичайного запуску Poshukach послідовно виконує три основні етапи:

```text
DHCP-журнали
    ↓
Агрегація пристроїв за MAC-адресою
    ↓
Список MAC-адрес з антивірусів
    ↓
Порівняння та класифікація
    ↓
CSV-результати і текстові звіти
```

### 1. Обробка DHCP-журналів

Програма:

- читає всі CSV-файли з `data\raw\dhcp\`;
- знаходить пристрої за MAC-адресами;
- об’єднує повторні підключення одного пристрою;
- зберігає останню IP-адресу, назву пристрою та джерело журналів;
- визначає першу й останню появу пристрою;
- підраховує кількість отримань мережевих налаштувань;
- визначає рандомізовані MAC-адреси;
- додає виробника мережевого адаптера з OUI-довідника.

Проміжний результат зберігається у:

```text
data\interim\dhcp.csv
```

### 2. Обробка списків антивірусного захисту

Програма читає CSV-файли з `data\raw\av-mac\`, знаходить у них MAC-адреси, приводить їх до єдиного формату та створює:

```text
data\interim\mac.csv
```

### 3. Порівняння та класифікація

MAC-адреси з DHCP-журналів порівнюються зі списком адрес, отриманих з антивірусних систем.

Після цього пристрої розподіляються за окремими категоріями: знайдені, не знайдені, ігноровані, мережеві, рандомізовані та можливі дублікати.

## Структура проєкту

```text
Poshukach/
├── configs/
│   ├── device_ignore.yml
│   ├── device_network.yml
│   └── local.yml
├── data/
│   ├── raw/
│   │   ├── dhcp/
│   │   ├── av-mac/
│   │   └── rds/
│   ├── cache/
│   ├── interim/
│   ├── result/
│   └── report/
├── scripts/
│   └── psh.py
├── tasks/
├── tests/
└── README.md
```

### Основні папки

| Папка | Призначення |
|---|---|
| `configs` | правила класифікації пристроїв |
| `data\raw` | вхідні файли користувача |
| `data\cache` | завантажений OUI-довідник |
| `data\interim` | проміжні оброблені таблиці |
| `data\result` | фінальні CSV-результати |
| `data\report` | текстові звіти |
| `scripts` | основний Python-скрипт |
| `tasks` | опис окремих задач і логіки розробки |
| `tests` | автоматизовані тести |

## Файли результатів

| Файл | Що містить |
|---|---|
| `dhcp-true.csv` | пристрої, MAC-адреси яких знайдено у списках антивірусів |
| `dhcp-false.csv` | пристрої, MAC-адреси яких не знайдено у списках антивірусів |
| `dhcp-ignore.csv` | пристрої, виключені з перевірки правилами `device_ignore.yml` |
| `dhcp-network.csv` | пристрої, визначені як мережеве обладнання правилами `device_network.yml` |
| `dhcp-random.csv` | пристрої з локально адміністрованими або рандомізованими MAC-адресами |
| `dhcp-dublicate.csv` | можливі дублікати, знайдені за однаковою назвою пристрою |
| `rds-*.csv` | результати обробки даних RDS, якщо використовується команда `rds` |
| `report-*.txt` | текстові звіти за окремими джерелами DHCP-журналів |

### `dhcp-false.csv`

Це основний файл для подальшої перевірки. Він містить пристрої, які отримували мережеві налаштування через DHCP, але їхні MAC-адреси не були знайдені у завантажених списках антивірусного захисту.

Наявність пристрою в цьому файлі не завжди означає відсутність антивірусу. Причиною також можуть бути:

- неповний або застарілий список з антивірусної системи;
- зміна мережевого адаптера;
- використання Wi-Fi замість Ethernet або навпаки;
- рандомізація MAC-адреси;
- помилка чи відсутність MAC-адреси у джерелі даних.

### `dhcp-ignore.csv`

Містить пристрої, які не потрібно перевіряти на наявність АВПЗ, наприклад:

- телефони та планшети;
- телевізори й мультимедійні пристрої;
- принтери;
- системи керування та IoT-пристрої;
- інші пристрої, визначені за назвою або виробником.

Правила задаються у:

```text
configs\device_ignore.yml
```

Підтримуються правила за:

- початком назви пристрою (`prefix`);
- частиною назви (`contains`);
- регулярним виразом (`regex`);
- виробником MAC-адреси (`vendor`);
- додатковими умовами `require` та винятками `except`.

Щоб додати новий пристрій до виключень, достатньо доповнити відповідний список у `device_ignore.yml`.

### `dhcp-network.csv`

Містить маршрутизатори, точки доступу, комутатори та інше мережеве обладнання.

Правила визначення зберігаються у:

```text
configs\device_network.yml
```

Пристрої можуть визначатися за:

- назвою;
- регулярним виразом;
- виробником мережевого адаптера;
- винятками для ПК, ноутбуків, телефонів та інших кінцевих пристроїв.

Один пристрій може потрапити до `dhcp-network.csv` незалежно від його наявності в інших категоріях, оскільки перелік мережевого обладнання формується окремим потоком.

### `dhcp-random.csv`

Містить пристрої з рандомізованими MAC-адресами. Такі адреси часто використовують сучасні телефони, планшети та ноутбуки для підвищення приватності.

За рандомізованою MAC-адресою неможливо надійно визначити реального виробника пристрою.

### `dhcp-dublicate.csv`

Містить записи, у яких одна назва пристрою пов’язана з кількома MAC-адресами. Це може виникати через:

- одночасне використання Ethernet і Wi-Fi;
- заміну мережевого адаптера;
- рандомізацію MAC-адрес;
- повторне використання однакової назви на різних пристроях.

## Налаштування правил

Файли в папці `configs` мають формат YAML. Після зміни правил повторно запустіть основний аналіз:

```bat
py scripts\psh.py
```

Перед редагуванням рекомендується створити резервну копію конфігураційного файла.

## Текстові звіти

Команда:

```bat
py scripts\psh.py report
```

створює окремий звіт для кожного джерела DHCP-журналів.

Звіт містить:

- період спостереження;
- кількість виявлених пристроїв;
- назву пристрою;
- MAC- та IP-адресу;
- дату останнього отримання мережевих налаштувань;
- загальну кількість появ пристрою за період.

## Доступні команди

```bat
py scripts\psh.py --help
```

Показати доступні команди.

```bat
py scripts\psh.py get_oui
```

Завантажити або оновити довідник виробників MAC-адрес.

```bat
py scripts\psh.py
```

Виконати повний аналіз DHCP-журналів і списків MAC-адрес.

```bat
py scripts\psh.py dhcp-aggregate
```

Обробити лише DHCP-журнали.

```bat
py scripts\psh.py mac-scan
```

Зібрати MAC-адреси з файлів антивірусних систем.

```bat
py scripts\psh.py compare-dhcp-mac
```

Повторно виконати порівняння вже створених проміжних файлів.

```bat
py scripts\psh.py rds
```

Обробити CSV-файли з `data\raw\rds\`.

```bat
py scripts\psh.py report
```

Створити текстові звіти.

## Якщо команда `py` не працює

Спробуйте ті самі команди, замінивши `py` на `python`:

```bat
python -m pip install PyYAML
python scripts\psh.py get_oui
python scripts\psh.py
```

Якщо Windows повідомляє, що Python не знайдено, перевстановіть Python і позначте пункт **Add python.exe to PATH**.
